# WooCommerce skill set

## Primary development skills

- `woo-extension-dev`: General Woo extension work, with domain references for registration, settings/admin, Cart/Checkout, HPOS/orders, blocks/Store API, and Abilities.
- `woo-block-theme-dev`: Woo block-theme templates and styling. Confirmed classic themes are out of scope.

## Auxiliary skill

- `woo-mcp-connect`: Standard WordPress MCP Adapter connection, Woo ability discovery, safe verification, and legacy Woo MCP migration.

Additional Woo domains should normally enter through `woo-extension-dev` and current docs. Add another top-level skill only when it has a distinct trigger and workflow that would otherwise make the primary skill ambiguous.
